# m1-assets / discovery — Customer Discovery Kit (2026-08-08)

Four artifacts, one loop:

1. **`community-target-list.md`** — 18 named, active communities (mid-2026) where agent
   builders discuss tool use and paid APIs, each with why-it-qualifies and a localized
   first post/DM draft, on a 2-hours/week founder schedule. The first posts are
   research asks — they recruit the interviews.
2. **`interview-guide.md`** — the 20-interview, 15-minute, non-leading guide: screener
   with quotas, recruiting script, time-boxed question spine with probes, discipline
   rules, and a per-interview YAML note template.
3. **`synthesis-template.md`** — coding rubric, rollup tables, and pre-committed
   decision thresholds that turn 20 interviews into (a) the publishable "what agents
   actually buy" list, (b) pilot recruiting criteria, (c) the M2 kill/pivot input.
4. **`x402-market-scan.md`** — what an agent can buy today: discovery layers, ~25 named
   live sellers with pricing (Exa $0.007/search, Firecrawl ~$0.01/scrape, BlockRun from
   $0.003/req, CoinGecko/Neynar $0.01, kenoodl $0.10, Bitrefill real-world goods, …),
   rails/facilitators, and the concrete ≤$0.25/tx pilot purchase sequence including the
   REFUSAL hero shot built from real third-party prices.

The loop: community post → interview → synthesis published back to the community →
invite-beta waitlist + pilots recruited against findings → M1/M2 gates.

Everything grounded in `docs/GOTOMARKET.md` (honest zeroes, no fake traction,
founder-voice posting, 2 h/week, engineering ≤10%). Prices and community links were
verified via public sources on 2026-08-08; re-verify live 402 challenges and Discord
invites before acting.
